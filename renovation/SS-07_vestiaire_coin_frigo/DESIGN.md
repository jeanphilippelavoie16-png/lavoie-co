# SS-07 — Vestiaire, coin frigo, escalier tournant

Copie de SS-06 (nouvel escalier, sous-sol repensé, bain sur pied, gym) ; SS-06 et les versions précédentes restent
intactes. Tout ce qui n'est pas listé ici est décrit dans `../SS-06_escalier_gym_bain/DESIGN.md`.

## Demandes
- Au lieu du coin bar, **une place pour ranger les manteaux**.
- **L'escalier en coin** pour sauver de l'espace.
- **Un petit coin pour le frigidaire** dans le séjour.
- Le **tapis roulant dans le même sens que le vélo**.

## Changements (P-107 sous-sol, P-108 rez-de-chaussée)
| Changement | Détail |
|---|---|
| **Vestiaire** (zone de l'ancien coin bar, près de la porte d'entrée) | banc de chêne de 5'-8" avec cases à souliers, 6 crochets laiton et tablette éclairée, armoires du haut ; **armoire à manteaux fermée** de 40 po ; mur vert forêt |
| **Escalier en coin** | on garde la bande de 3 pi dessinée sur A-101 et on tourne dans le coin du haut : **3 marches tournantes** dans le carré de 3 × 3 pi contre le mur arrière (pivot côté droit), sortie vers la droite au rez-de-chaussée ; maintenant dessinées en éventail sur les deux plans et modélisées en 3D. Pas de palier carré : c'est ce qui sauve le plus d'espace |
| **Coin frigo** dans le séjour | niche en chêne contre le mur de droite, entre la fenêtre et la porte d'entrée : garde-manger de 18 po, **frigo inox de 30 po**, armoire au-dessus ; prise dédiée à prévoir |
| Coin lecture | deux fauteuils de cuir cognac côte à côte devant la fenêtre de devant, petite table entre les deux |
| **Gym** | tapis roulant tourné **dans le même sens que le vélo** (console vers le séjour, le long du miroir) ; poids au sol entre les deux ; 36 po libres derrière le tapis |

## À valider
Marches tournantes : giron minimal à la ligne de foulée selon le code ; main courante continue. Les autres points
(hauteur d'étage, trémie, coupe-feu, fenêtre arrière de la chambre 1, drains de la salle de bain) restent ceux de SS-06.
