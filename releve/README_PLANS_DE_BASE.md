# Plans de base — relevé de l'existant R0

Les fichiers de `releve/livrables/` sont les **plans de base** de la maison (relevé de l'existant R0, figé au commit `59ac401`,
étiquette git locale `plans-de-base-R0`). Ils ne sont pas modifiés par les projets de rénovation.

Les projets se font dans `renovation/<code>_<nom>/`, à partir d'une copie de `releve/livrables/donnees/maison.json`
(voir `renovation/README.md`).
